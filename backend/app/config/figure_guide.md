# 科研绘图规范（Figure Guide）

> **绘图前必须先读取本文件并严格遵循。**
> 绘图环境已在启动时注入以下常量与全局样式，**直接使用，禁止 import 额外样式库、禁止 `sns.set_theme()`、禁止修改 `font.*`**：
>
> - `COLORS` / `DEFAULT_COLORS`：配色
> - `FIG_SINGLE` / `FIG_DOUBLE` / `FIG_WIDE` / `FIG_SQUARE`：图尺寸
> - 全局 rcParams：中文字体、去掉上右边框、300dpi、图例无边框

---

## 一、配色规范（最容易暴露"业余"的地方）

**必须用 `COLORS` 或 `DEFAULT_COLORS`，禁止用 matplotlib 默认色、CSS 色名、`tab10`。**

| 用途              | 颜色                                              |
| ----------------- | ------------------------------------------------- |
| 主方法 / 本文结果 | `COLORS['primary']`（深蓝）                     |
| 对比方法 / 基准   | `COLORS['secondary']`（珊瑚红）                 |
| 第三系列 / 补充   | `COLORS['tertiary']`（绿）                      |
| 参考线 / 背景     | `COLORS['neutral']`（灰）                       |
| 置信带 / 辅助填充 | `COLORS['light']`（浅蓝，配 `alpha=0.2~0.3`） |

配色语义规则：

- 同一张图**一个主色系 + 少量对比色**，不要每根线一个颜色。
- 需要更多系列时，用 `DEFAULT_COLORS` 依次取色；同系列用同色不同 `alpha`（0.2–1.0）区分。
- 禁止：`#1f77b4`（matplotlib 默认蓝）、`'blue'/'red'/'green'` 等 CSS 名、`RdYlGn`（红绿灯）、`RdBu_r`（过深）、`dark_background` 主题。

**系列超过 5 个或需要更"科研"的色感时，可用以下备用配色（三选一，直接写 hex）：**

- 柔和系：`['#5B9BD5', '#ED7D7D', '#7BC8A4', '#B0B0B0', '#9B8EC4', '#F4A261']`（柔蓝/珊瑚粉/薄荷绿/浅灰/淡紫/暖杏）
- 学术系：`['#3C5488', '#E64B35', '#00A087', '#4DBBD5', '#F39B7F']`（深蓝/红/绿/天蓝/橙）
- 科研配色：`['#2C6E7E', '#1FAE9D', '#7BC48F', '#F2C14E', '#F28E2B','#E4572E','#E63946','#4D4D4D']`（深青蓝/青绿色/薄荷绿/暖黄色/橙/朱红/珊瑚红/石墨灰）
- 每张图只用**一套**配色，并且同一篇论文也只能选择一种配色方案，前后章节保持一致；不要在两张图里用两套完全不同风格的色板。

## 二、防残图铁律（最高优先级，违反 = 图不可用）

1. **Y 轴必须保留数值刻度**，禁止 `ax.set_yticks([])`——没刻度的轴不可读。稀疏（3–5 个）可以，空不行。
2. **`set_xlabel()` 和 `set_ylabel()` 必须都有，且带单位**（如 `时间 (h)`、`RMSE`、`%`）。禁止裸轴。
3. 若隐藏 X 刻度（`set_xticks([])`），**必须直接标注数据**（`ax.bar_label` / `ax.text` / `annotate`）。隐藏刻度又不标数据 = 残图。
4. **每个 `fill_between` 置信带必须配主曲线**（同一次 `ax.plot`），禁止只有色块没有线。
5. `ax.set_frame_on(False)` **只允许热力图/图片类**，折线/柱状/散点一律保留左+下边框。
6. 多面板（subplots）：**每个子图都必须有可见的坐标轴和标签**，禁止出现漂浮的色块。
7. 画完自检：去掉标题后，**单看这张图能否读懂坐标含义？** 不能就是残图，必须补全。

## 三、样式细节（科研级与默认样式的分水岭）

- **图例**：`frameon=False`（已全局配置），位置不遮挡数据（数据在右上则图例放左上，或用 `bbox_to_anchor`）。
- **标注关键统计量**：相关图标注 `r`/`p`，拟合图标注 `R²`/`MAE`/`RMSE`，用 `ax.annotate` 或 `ax.text` 标在空白处。
- **误差棒**：`elinewidth=2, capthick=2, capsize=10`。
- **数据标签**：柱状图用 `ax.bar_label` 标数值；折线图在极值点标注具体数值。
- **参考线**：基线/阈值用 `ax.axhline` / `ax.axvline`（灰色虚线）+ 图例或标注说明。
- **热力图/混淆矩阵**：文字颜色自适应（深色格白字、浅色格黑字）；格内数值保留合适小数位。
- **网格**：默认无网格；需要时只用稀疏的 Y 向网格（`ax.grid(axis='y', alpha=0.3)`）。
- **坐标轴标签**：包含变量名 + 单位；中文论文用中文标签，英文论文用英文。
- **子图标签**：多面板用 `(a) (b) (c)`，`ax.set_title('(a)', loc='left', fontweight='bold', pad=3)`。

## 四、图表类型选择（对号入座，避免千篇一律）

| 数据特征              | 首选图表                                     |
| --------------------- | -------------------------------------------- |
| 方法对比（≤4 个）    | 分组柱状图                                   |
| 排名 / 计数（≥5 类） | 水平条形图（排序 + 渐变/高亮）或棒棒糖图     |
| 时间序列 / 趋势       | 折线图 + 置信带（`fill_between`）          |
| 分布比较              | 箱线图 / 小提琴图（配散点更好）              |
| 相关性矩阵            | 热力图                                       |
| 占比 / 构成           | 堆叠柱状图 / 环形图                          |
| 参数敏感性            | 热力图 / 等高线 / 带阴影的折线               |
| 优化收敛              | 收敛曲线（标注最终值）                       |
| 预测效果              | 真实值-预测值散点（含 y=x 参考线）+ 误差分布 |
| 综合得分排序          | 水平条形图 / 雷达图                          |

- **全文图表类型要有多样性**：同一类型在一篇论文里最多出现 2 次。
- 数据点很少（<15）优先用散点/折线，不用柱状。

**精细决策（进阶）**：

| 数据形状                   | 首选图表                                       |
| -------------------------- | ---------------------------------------------- |
| A vs B（2 方案、多指标）   | 哑铃图（Dumbbell）优于分组柱状                 |
| 相对基线变化（±%）        | 发散柱状图（Diverging Bar）                    |
| 消融/模块贡献              | 瀑布图（Waterfall）优于普通柱状                |
| 分布比较（5–15 组）       | 岭图（Ridgeline）；2–4 组×多类用分组小提琴图 |
| 时间序列（4+ 条线）        | 小倍数子图网格，避免"面条图"                   |
| 2 方案前后对比（配对样本） | 配对点图（Paired Dot）优于分组柱状             |
| 多模型统计对比             | 泰勒图（Taylor）优于三张独立柱状图             |
| 特征重要性                 | SHAP 蜂群图（有 SHAP 值时）优于水平条形        |
| 大样本二维联合分布         | Hexbin + 边际直方图，避免散点重叠              |

**反模式升级**（尽量升级，除非受众熟悉传统图）：

| 不要                | 改成                                                  |
| ------------------- | ----------------------------------------------------- |
| 饼图                | 环形图（Donut）                                       |
| 排名柱状图          | 棒棒糖图（Lollipop，更干净）                          |
| 纯箱线图            | Rain Cloud（小提琴+箱线+散点，样本>20 时）            |
| 纯热力图            | 热力图 + 聚类树状图（行列有序时）                     |
| 简单柱状（消融）    | 瀑布图                                                |
| `RdYlGn` colormap | `coolwarm`（发散）或 `YlOrRd`/`viridis`（顺序） |

## 五、尺寸与保存

- **figsize 高度不超过 8 英寸**（约 20cm），否则图占满整页。
- 用注入的尺寸常量：单图 `FIG_SINGLE`、双栏对比 `FIG_DOUBLE`、宽图 `FIG_WIDE`、方形 `FIG_SQUARE`。
- 多面板：面板数 ≤ 4，2-panel 用 `FIG_DOUBLE`，4-panel 用 `plt.subplots(2,2)` + 合适宽度。
- 条目很多（20+）时：只展示 Top 15–20，其余放表格；或换更紧凑的图表类型。
- **保存用 `plt.savefig('xxx.png', dpi=300, bbox_inches='tight')` 后 `plt.close()`**（避免重复画布）。

## 五·五、多维数据图（核心！1 张多维图 胜过 N 张单维图）

> **遇到 ≥3 个相关变量时，必须优先合并成一张多维图，禁止拆成多张单变量/双变量图**（拆开会造成图表数量爆炸、评委观感差）。下面是从科研绘图模板库提炼的高效多维画法。

### 合并优先的铁律

- 单张图能表达的，**绝不拆成多张**。3 个及以上相关变量 → 用本节的合并图，不要每个变量各画一张折线/柱状。
- 同一子任务各图能合并的必须合并：同趋势多序列 → 分面折线（FacetGrid）；同分布多组 → 小提琴图。
- **全文图数建议 13-18 张**，单子任务建议 4-6 张（保持合并优先，不要无谓堆图）。超过 20 张时应主动合并或删除最弱相关的图。
- 判断标准：如果两张图只是"换了个变量、结构完全一样"，就必须合并成一张多维图。

### 1. 相关矩阵 PairGrid（多维两两分布 + 相关系数）

适用：多个数值变量互相看关系（分布 + 散点拟合 + 相关性）。`seaborn` 或自绘均可用，关键结构：

- **下三角**：散点 + 回归线 + 置信带（`fill_between`）+ 标注 `r`/显著性星级
- **对角线**：单变量分布（直方图 + KDE 密度叠加）
- **上三角**：相关系数色块（`cmap('RdBu_r')` 取色，`abs(r)>=0.55` 用白字，弱相关补小方点）
- 相关系数标注：`r` 数值 + 显著性（`p<0.05` 打 `*`，`<0.01` 打 `**`，`<0.001` 打 `***`）
- 一张图同时展示：两两分布、线性趋势、方差、相关性——**4 类信息合一**，是对应 N 张单维图的最佳替代。

### 2. 分组相关矩阵 + 半边小提琴（多维特征对二维目标的影响）

适用：多个输入特征 vs 训练/测试（或方案A/B）的分布对比。

- 左半：**下三角相关矩阵**（`RdBu_r` 色块，弱相关小方点，边缘画特征分组括号 + 组名）
- 右半：**半边小提琴图**（每特征一列，训练/测试两侧分开，KDE 密度 + 四分位虚线 + 对数轴适用）
- 一张图把"特征相关性 + 特征分组 + 双态分布差异"全放进去，替代"相关热图 + N 个分布图"。

### 3. 泰勒图 Taylor Diagram（多模型对比，替代多张柱状）

适用：多个模型/方法对比预测精度。比"N 张柱状图逐模型画 RMSE/相关系数"信息密度高得多。

- 极坐标：横轴=标准差，纵轴=相关系数，参考点置坐标系原点
- 以中心参考点为半径，画同心圆（标准差刻度）+ 相关系数射线 + 中心 RMS 差轮廓（虚线）
- 每个模型一个散点（有色圆点），"Observed" 用黑点放参考位置
- 一张图同时展示每个模型的：标准差、与观测的相关系数、RMS 误差——**3 个统计量合一**。
- 可做 2-3 个面板（训练/测试/全量），每面板一个字母标签 `(a)(b)(c)`。

### 4. 预测-真实边缘分布组合图（预测评估合并）

适用：预测模型效果展示（替代"真实值vs预测散点" + 若干分布图）。

- 每模型一个小网格：左上=真实值分布(KDE+直方)，右上=预测值分布，主区=真实vs预测散点（含 `y=x` 参考线 + 空心散点区分训练/测试）
- 主区角落用白底框标注 `R²` / `RMSE`（训练、测试分开写）
- 网格用 `GridSpecFromSubplotSpec`，`height_ratios=[0.30, 1.0]`、`width_ratios=[1.0, 0.34]`，左上/右上空白面板 `axis('off')`
- 一张图同时展示：真实/预测分布、散点拟合、误差指标——**比"散点图+直方图分开画"少 2-3 张图**。

### 5. 分面合并（多组同结构 → 一格一图）

适用：同一指标在多个子类/方案下重复比较。

- `FacetGrid`/`subplots` 按类别分面，每格同类图，共用坐标轴范围
- 子图标签 `(a)(b)(c)`，`sharey=True` 让高度可比
- 单格最多 4 个面板，避免"每类一张全尺寸图"

### 注意事项
- 多维图里**每个子图仍必须满足"防残图铁律"**：有轴、有标签、有单位、格内数值可读（不要为了"一格一图"牺牲可读性）。
- 相关系数字体随格色自适应：深色格白字、浅色格黑字。
- **禁止**：为凑数量把多维图硬拆成单维图，也禁止"所有图都用 PairGrid/泰勒图"（要有类型多样性，每类最多出 2 次）。

## 六、禁止项（检查清单）

- ❌ 3D 图表（除非展示真实 3D 数据）
- ❌ 饼图（改用水平条形图）
- ❌ 图内大标题（`ax.set_title('某某分析')`——标题交给论文 caption，面板标签 `(a)(b)` 除外）
- ❌ 密集网格、四边完整边框（只保留左+下）
- ❌ matplotlib 默认配色 / CSS 色名 / `tab10` / 难看 colormap
- ❌ 无单位坐标轴、裸轴、无图例的对比图
- ❌ 硬编码假的演示数据（必须用真实计算结果）

## 七、画图前流程 & 画完自检

**画图前**：

1. 确认要画的图表类型（对照第四节决策表）。
2. 确认数据已就绪（从计算结果读取，不硬编码）。

**画完自检（逐项过）**：

- [ ] 坐标轴有标签且带单位？
- [ ] Y 轴有数值刻度（非空）？
- [ ] 用了 `COLORS`，不是默认蓝？
- [ ] 图例存在且不遮挡数据？
- [ ] 关键统计量（r / R² / MAE / RMSE）有标注？
- [ ] 每个置信带有对应主曲线？
- [ ] 多面板每个子图可读？
- [ ] 300dpi 保存？

## 八、高级效果库（让图从"能看"到"专业"，按需叠加）

> 用 matplotlib 原生实现即可，不需要额外库。每张图至少叠加 2-3 个下列效果。

**柱状图**

- 淡色填充 + 原色边框：`ax.bar(x, v, color=淡色, edgecolor=原色, linewidth=1.2)`
- 顶部数值标注：`ax.text(bar.get_x()+w/2, bar.get_height()+0.5, f'{v:.1f}', ha='center', va='bottom')`
- 最优值 ★ 高亮：最优柱数值前加 `★` 并加粗、用主色
- 误差棒：`yerr=..., capsize=3`
- 水平参考线：`ax.axhline(全局均值, color='gray', ls='--', alpha=0.6)`

**折线图**

- 数据点标记：`ax.plot(x, y, 'o-', markersize=5, linewidth=1.5, color=主色)`
- 置信带：`ax.fill_between(x, y_low, y_high, alpha=0.15, color=主色)`（必须配主曲线）
- 极值点标注：在最大/最小点用 `ax.annotate` 标出具体数值
- 双量纲双轴：`ax2 = ax.twinx()`（两条不同单位的曲线）

**散点图**

- 回归线 + 公式框：`numpy.polyfit` 画拟合线，`ax.text` 标 `R²`/`r`、`p`（白底圆角框 `bbox=dict(boxstyle='round', facecolor='white', alpha=0.8)`）
- 预测效果图：加 `y=x` 虚线参考线

**热力图 / 相关性矩阵**

- 只显下三角：`mask = np.triu(np.ones_like(corr, bool), k=1)` + `sns.heatmap(corr, mask=mask, annot=True, fmt='.2f', cmap='coolwarm', center=0)`
- 格内数值：`annot=True`（深色格白字、浅色格黑字）

**分布图**

- Rain Cloud：半小提琴 + 箱线 + 抖动散点 + 均值菱形（比纯箱线更有信息量）

**森林图（回归系数/效应量）**

- `ax.errorbar(coefs, y_pos, xerr=[低-点, 点-高], fmt='o', capsize=4, markersize=6)` + `ax.axvline(x=0, ls='--', alpha=0.7)`

**多面板**

- 面板数 ≤ 4；每个面板必须有可见坐标轴；子图标签用 `ax.set_title('(a)', loc='left', fontweight='bold', pad=3)`（不要用 `ax.text(transAxes)`）

## 九、防遮挡与常见丑图（画完逐项检查）

**防遮挡**

- 图例放空白区域（数据在右上 → 图例左上；或用 `bbox_to_anchor` 移到图外），禁止盖住曲线/柱子。
- 数值标注互相重叠：相邻标签错开（`offset`）或加白色 `bbox` 背景。
- 多曲线重叠：用不同颜色 + 线型区分，同一色系不同 `alpha` 只用于同系列。

**常见丑图（必须避免）**

- ❌ 全图单一默认蓝（用多色配色方案）
- ❌ 图内 `plt.title()` 大标题
- ❌ `jet` colormap（色盲不友好；用 `coolwarm`/`viridis`）
- ❌ 默认灰色网格线（去掉或极淡虚线）
- ❌ 坐标轴标签用变量名（如 `col_1`），必须是含义明确的中文/英文 + 单位
- ❌ 字体太小（打印后看不清，最终 ≥ 9pt）
- ❌ 图与图之间配色风格不一致
